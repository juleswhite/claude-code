# GILDCO Website Content

Create or update web content for: $ARGUMENTS

## Brand Voice
- Tagline: "Más capacidad humana. Mejor tecnología. Mayor productividad."
- Closing phrase: "Encontramos capacidad atrapada. Implementamos cómo liberarla. Medimos cuánto valor recuperamos."
- Tone: confident, data-driven, human-centered (not cold/corporate)
- GILDCO is one indivisible word — the "CO" is NOT from "company"
- Name origin: "gilding" (revealing existing value) + "guild" (expert network)

## Differentiation (always reflect this)
- NOT an HR consultancy (just climate surveys)
- NOT a software vendor (just selling a tool)
- NOT a transformation consultancy (just saying what to digitize)
- GILDCO quantifies the problem, identifies root causes, proposes mixed interventions (process + training + AI), and measures results

## Content Guidelines
1. Lead with the client's problem, not GILDCO's solution
2. Use concrete numbers and examples when possible
3. Spanish (Colombian), professional but approachable
4. Every section should connect to measurable outcomes
5. CTAs should drive toward the diagnosis as entry point

## Design Constraints
- Content must work within: cream backgrounds (#F7F6F3), graphite text (#1C1A17)
- Accent elements in deep purple (#5B4FD1)
- Data visualizations use terracotta (lost capacity) and teal (recoverable)

## Output
- Save content to `web-content/{section-name}.md`
- Include suggested heading hierarchy (H1, H2, H3)
- Note where data visualizations or icons would enhance the message
